# XAMPP Server Port Change Guide (Port 80 → 8000)

> **Purpose:** Run XAMPP and Laragon **simultaneously** on the same machine for separate development environments.
>
> **Before:** XAMPP used default ports (HTTP `80`, HTTPS `443`, MySQL `3306`) — these **clash** with Laragon.
>
> **After this guide:**
>
> | Service | Old URL | New URL |
> |---------|---------|---------|
> | XAMPP Web | `http://localhost/` | `http://localhost:8000/` |
> | XAMPP phpMyAdmin | `http://localhost/phpmyadmin/` | `http://localhost:8000/phpmyadmin/` |
> | XAMPP HTTPS (SSL) | `https://localhost/` | `https://localhost:8001/` |
> | XAMPP MySQL | port `3306` | port `3307` |

---

## 1. Folder Structure Overview

```
C:\xampp\
├── apache\
│   └── conf\
│       ├── httpd.conf                  ← STEP 1  (Apache HTTP port)
│       └── extra\
│           ├── httpd-ssl.conf          ← STEP 2  (Apache HTTPS port)
│           └── httpd-xampp.conf        ← STEP 4  (phpMyAdmin access)
├── mysql\
│   └── bin\
│       └── my.ini                      ← STEP 3  (MySQL port)
└── phpMyAdmin\
    └── config.inc.php                  ← STEP 3  (phpMyAdmin → MySQL port)
```

> ⚠️ **Always stop Apache & MySQL** from the XAMPP Control Panel before editing these files, then **restart** them after saving.

---

## STEP 1 — Change Apache HTTP Port (80 → 8000)

### File Path
```
C:\xampp\apache\conf\httpd.conf
```

### File #1 — `Listen` directive (line 60)

**Before:**
```apache
# prevent Apache from glomming onto all bound IP addresses.
#
#Listen 12.34.56.78:80
Listen 80                                              ← line 60
```

**After:**
```apache
# prevent Apache from glomming onto all bound IP addresses.
#
#Listen 12.34.56.78:80
Listen 8000                                             ← line 60
```

### File #2 — `ServerName` directive (line 228)

**Before:**
```apache
ServerName localhost:80                                 ← line 228
```

**After:**
```apache
ServerName localhost:8000                               ← line 228
```

---

## STEP 2 — Change Apache HTTPS/SSL Port (443 → 8001)

> SSL is optional but must be moved too, or Apache will error `AH00072` on port 443 (which Laragon uses).

### File Path
```
C:\xampp\apache\conf\extra\httpd-ssl.conf
```

### File #1 — `Listen` directive (line 36)

**Before:**
```apache
# standard HTTP port (see above) and to the HTTPS port
#
Listen 443                                              ← line 36
```

**After:**
```apache
# standard HTTP port (see above) and to the HTTPS port
#
Listen 8001                                             ← line 36
```

### File #2 — `<VirtualHost>` block (line 121)

**Before:**
```apache
<VirtualHost _default_:443>                             ← line 121
```

**After:**
```apache
<VirtualHost _default_:8001>                            ← line 121
```

### File #3 — `ServerName` directive (line 125)

**Before:**
```apache
ServerName www.example.com:443                          ← line 125
```

**After:**
```apache
ServerName www.example.com:8001                         ← line 125
```

---

## STEP 3 — Change MySQL Port (3306 → 3307) & phpMyAdmin

> Laragon's MySQL also binds to `3306`. Running both on `3306` means only one can start — the other fails. Change XAMPP's MySQL to `3307` and tell phpMyAdmin to connect there.

### File #1 — MySQL config

#### File Path
```
C:\xampp\mysql\bin\my.ini
```

**`[client]` section (line 20):**
```ini
[client]
# password       = your_password
port=3307                                               ← line 20 (was 3306)
```

**`[mysqld]` section (line 29):**
```ini
# The MySQL server
default-character-set=utf8mb4
[mysqld]
port=3307                                               ← line 29 (was 3306)
```

> Only the two **active** `port=` lines matter. The other `3306` mentions later in the file are in **comments** and replication help-text — leave them alone.

### File #2 — phpMyAdmin config

#### File Path
```
C:\xampp\phpMyAdmin\config.inc.php
```
Add the `port` line right after the `host` line so phpMyAdmin connects to XAMPP's MySQL (`3307`), not Laragon's (`3306`).

**Before (lines 26-29):**
```php
/* Bind to the localhost ipv4 address and tcp */
$cfg['Servers'][$i]['host'] = '127.0.0.1';              // line 27
$cfg['Servers'][$i]['connect_type'] = 'tcp';            // line 29
```

**After (line 28 added):**
```php
/* Bind to the localhost ipv4 address and tcp */
$cfg['Servers'][$i]['host'] = '127.0.0.1';              // line 27
$cfg['Servers'][$i]['port'] = '3307';                   // line 28 (NEW)
$cfg['Servers'][$i]['connect_type'] = 'tcp';            // line 29
```

## STEP 4 — Allow phpMyAdmin Access from LAN IP (optional)

> By default XAMPP restricts phpMyAdmin to localhost (`Require local`). To reach it from `http://192.168.1.120:8000/phpmyadmin/` (your LAN IP) **and** from `http://localhost:8000/phpmyadmin/` (which uses IPv6 `::1`), add all three allow rules.

### File Path
```
C:\xampp\apache\conf\extra\httpd-xampp.conf
```

### `Alias /phpmyadmin` block (lines 91-97)

**Before:**
```apache
Alias /phpmyadmin "C:/xampp/phpMyAdmin/"                 ← line 91
<Directory "C:/xampp/phpMyAdmin">
    AllowOverride AuthConfig
    Require local                                        ← line 94
    ErrorDocument 403 /error/XAMPP_FORBIDDEN.html.var
</Directory>
```

**After:**
```apache
Alias /phpmyadmin "C:/xampp/phpMyAdmin/"                 ← line 91
<Directory "C:/xampp/phpMyAdmin">
    AllowOverride AuthConfig
    Require ip 192.168.1.120                             ← line 94 (LAN IPv4)
    Require ip 127.0.0.1                                 ← line 95 (localhost IPv4)
    Require ip ::1                                       ← line 96 (localhost IPv6)
    ErrorDocument 403 /error/XAMPP_FORBIDDEN.html.var
</Directory>
```

> 🔎 **Troubleshooting tip:** If `http://localhost:8000/phpmyadmin/` redirects back to the web homepage, open `C:\xampp\apache\logs\error.log`. A line like `client denied by server configuration` with `[client ::1:...]` means your browser connected over **IPv6 loopback (`::1`)** which wasn't allowed — add `Require ip ::1` as shown above.

## STEP 5 — Change LAN IP (e.g. `192.168.0.151` → `192.168.1.120`)

> If your machine's local network IP changes, the **only** XAMPP file that references it is the phpMyAdmin access rule added in STEP 4. Ports are never tied to the machine IP, so this is a single, quick change.

### File Path
```
C:\xampp\apache\conf\extra\httpd-xampp.conf
```

### `Alias /phpmyadmin` block (line 94)

**Before (old LAN IP):**
```apache
    Require ip 192.168.0.151                             ← line 94 (old LAN IPv4)
    Require ip 127.0.0.1                                 ← line 95 (localhost IPv4)
    Require ip ::1                                       ← line 96 (localhost IPv6)
```

**After (new LAN IP):**
```apache
    Require ip 192.168.1.120                             ← line 94 (NEW LAN IPv4)
    Require ip 127.0.0.1                                 ← line 95 (localhost IPv4)
    Require ip ::1                                       ← line 96 (localhost IPv6)
```

> ⚠️ `127.0.0.1` and `::1` (localhost rules) **do not need to change** — they are the loopback addresses and stay the same regardless of your LAN IP.

### After changing the IP

1. **Restart Apache** from the XAMPP Control Panel.
2. Verify your new IP is active first (`ipconfig` on Windows → look under the active adapter's **IPv4 Address**).
3. Test the new LAN URL:

| Test | URL |
|------|-----|
| phpMyAdmin (new LAN IP) | `http://192.168.1.120:8000/phpmyadmin/` |
| phpMyAdmin (localhost) | `http://localhost:8000/phpmyadmin/` |

---

## Post-Change Verification

1. **Restart** Apache & MySQL from the XAMPP Control Panel (never just close the window — use Stop then Start).
2. Check the Control Panel shows **green** (running) for Apache and MySQL.
3. Open a browser and test:

| Test | URL |
|------|-----|
| XAMPP web home | `http://localhost:8000/` |
| phpMyAdmin (localhost) | `http://localhost:8000/phpmyadmin/` |
| phpMyAdmin (LAN) | `http://192.168.1.120:8000/phpmyadmin/` |
| XAMPP HTTPS | `https://localhost:8001/` |

4. In phpMyAdmin, the server should read **port `3307`** in the connection info.

> ✅ Laragon stays untouched on its defaults (`80` / `443` / `3306`) — both stacks can now run side by side, each using its **own** Apache, MySQL, and data directories.
