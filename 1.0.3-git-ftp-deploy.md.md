# Git FTP Setup Guide (Fresh PC)

## Prerequisites

Install the following on a fresh Windows PC:

1. **Git for Windows** - https://git-scm.com/download/win
   - This includes Git Bash, `ssh`, `curl`, and all needed tools
   - Make sure to select "Add Git Bash to your terminal" during install

2. **git-ftp** - https://github.com/git-ftp/git-ftp
   - Download the latest release zip
   - Extract to `C:\Users\<YourUser>\.git-ftp\`
   - You should have: `C:\Users\<YourUser>\.git-ftp\git-ftp`

---

## Step 1: Add git-ftp to PATH

Add `C:\Users\<YourUser>\.git-ftp` to your system PATH so `git ftp` works:

```powershell
# Run in PowerShell (as your user)
[Environment]::SetEnvironmentVariable("Path", $env:Path + ";C:\Users\<YourUser>\.git-ftp", "User")
```

Or manually: System Properties > Environment Variables > Path > Edit > Add `C:\Users\<YourUser>\.git-ftp`

**Restart your terminal after this.**

---

## Step 2: Fix SSH Host Key for SFTP (Critical!)

The `curl` bundled with Git for Windows uses `libssh2` which does **not** support `ssh-ed25519` host keys. If your server uses ed25519 (most modern servers do), you must add the RSA host key instead.

Run this once:

```bash
# Scan the server for its RSA host key and save it
ssh-keyscan -t rsa sirikotiamadrasha.com >> ~/.ssh/known_hosts 2>/dev/null
```

If you already have an ed25519-only entry in `known_hosts` for the host, remove it first:

```bash
# Open ~/.ssh/known_hosts in Notepad and delete the line with the host
notepad ~/.ssh/known_hosts
```

Then re-add with RSA:

```bash
ssh-keyscan -t rsa sirikotiamadrasha.com >> ~/.ssh/known_hosts 2>/dev/null
```

---

## Step 3: Configure git-ftp for Your Project

Clone your repo, then run these commands inside the repo directory:

```bash
cd /path/to/your/repo

# Set the remote URL (SFTP path to your deployment directory)
git config git-ftp.url "sftp://yourdomain.com/home/youruser/public_html/yourproject/"

# Set your FTP/SSH username
git config git-ftp.user "yourusername"

# Set your password
git config git-ftp.password "yourpassword"

# Set the port (22 for SFTP, default can be omitted)
git config git-ftp.port 22
```

### Example:

```bash
git config git-ftp.url "sftp://sirikotiamadrasha.com/home/sirikoti/public_html/test-dev/"
git config git-ftp.user "sirikoti"
git config git-ftp.password "Cpanel@2025"
git config git-ftp.port 22
```

> **Note:** The `@` and other special characters in your password are automatically URL-encoded by git-ftp. Store the password as plain text in the config.

---

## Step 4: Initial Upload

```bash
# If using Git Bash directly:
git ftp init

# If git ftp command not found, run via Git Bash explicitly:
"C:\Program Files\Git\bin\bash.exe" -c "export PATH='/mingw64/bin:/usr/bin:$PATH'; git ftp init"
```

This uploads all tracked files and creates a `.git-ftp-version` file on the server.

---

## Step 5: Deploying Updates

After making changes and committing them:

```bash
# Push only changed files since last deployment
git ftp push

# Force push all files (ignoring tracked changes)
git ftp push -f
```

## Troubleshooting

### "Can't access remote" Error

1. **Check your URL format** - Do NOT include the username in the URL. Use:
   - Correct: `sftp://domain.com/path/`
   - Wrong: `sftp://user@domain.com/path/`

2. **Check SSH host key** - See Step 2. This is the most common cause.

3. **Test SFTP connection manually:**
   ```bash
   curl -v "sftp://yourdomain.com/path/" --user "youruser:yourpassword"
   ```

### "Protocol 'sftp' not supported by curl"

Your system `curl` doesn't support SFTP. Git Bash's curl does. Make sure `/mingw64/bin` is first in your PATH inside Git Bash:

```bash
export PATH='/mingw64/bin:/usr/bin:$PATH'
```

### Password with Special Characters

git-ftp handles URL encoding automatically. Store your password as plain text:

```bash
# This is correct even with @ in the password:
git config git-ftp.password "Cpanel@2025"
```

Do NOT URL-encode it yourself (e.g., `%40` instead of `@`). git-ftp will double-encode it.

### SSH Key Authentication (Optional)

Instead of password, you can use SSH keys:

```bash
# Use private key
git config git-ftp.key ~/.ssh/id_rsa

# Use public key
git config git-ftp.pubkey ~/.ssh/id_rsa.pub
```

## Quick Reference

| Command | Description |
|---------|-------------|
| `git ftp init` | First-time upload of all files |
| `git ftp push` | Upload only changed files |
| `git ftp push -f` | Force upload all files |
| `git ftp catchup` | Mark current state as deployed (without uploading) |
| `git ftp download` | Download remote SHA1 file |
| `git ftp cat` | Show remote SHA1 |

---

## One-Line Deploy (Git Bash)

Add this alias to your `~/.bashrc` for quick deploys:

```bash
alias deploy='export PATH="/mingw64/bin:/usr/bin:$PATH"; git ftp push'
```

Then just run `deploy` after committing changes.
